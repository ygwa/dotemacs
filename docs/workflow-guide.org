* 快速入门

**第一次使用**

1. 初始化目录结构
   - 确保 =~/Documents/org/= 目录存在
   - 创建子目录：=roam/=（用于 Org Roam）、=library/=（用于文献）
   - 创建 =inbox.org= 文件用于快速收集

2. 查看快捷键
   - 按 =C-c ?= 查看完整的快捷键帮助

3. 创建第一篇笔记
   - 按 =F7= 快速创建待办事项
   - 按 =F8= 快速创建笔记
   - 按 =F9= 查找或创建 Roam 笔记

* 核心工作流

**1. 收集与整理**

*快速收集*
| 快捷键 | 功能                      |
|--------+---------------------------|
| F7     | 创建待办事项              |
| F8     | 创建笔记（存入 inbox.org） |
| F9     | 创建/查找 Roam 笔记       |


*查看任务*
| 快捷键  | 功能                         |
|---------+------------------------------|
| C-c a   | 打开 Agenda（默认今日视图）   |
| C-c a g | 我的日程（今日 + 进行中任务） |
| C-c a w | 本周任务                     |
| C-c a p | 按优先级查看所有任务          |
| C-c a t | 按标签查看任务               |

*处理收集箱*
- =C-c c= - Org Capture（更多模板选择）

可用的 Capture 模板：
- =t= - Todo [inbox]
- =n= - Note [inbox]
- =m= - Meeting（会议记录）

**2. 知识管理（Org Roam）**

*创建笔记*
| 快捷键  | 功能           |
|---------+----------------|
| C-c n f | 查找或创建笔记 |
| C-c n i | 插入笔记链接   |
| C-c n d | 创建每日日记   |

*笔记模板*
使用 =C-c n f= 时，可选择以下模板：
- =d= - default/concept（概念笔记）
- =l= - literature（文献笔记）
- =q= - question（问题探究）
- =i= - idea（想法记录）
- =p= - blog post（博客文章）

*浏览笔记*
| 快捷键  | 功能                                     |
|---------+------------------------------------------|
| C-c n l | 切换 Roam 缓冲区（显示当前笔记的反向链接） |
| C-c n r | 最近修改的笔记                           |
| C-c n b | 书签笔记（标记了 :bookmark: 标签的笔记）  |
| C-c n [ | 前一天的日记                             |
| C-c n ] | 后一天的日记                             |

*可视化*
| 快捷键  | 功能                              |
|---------+-----------------------------------|
| C-c u o | 打开 Org Roam UI（浏览器中的图谱） |
| C-c u f | 在 UI 中跟随当前节点               |

**3. 文献管理**

*安装依赖*
#+BEGIN_SRC bash
# 安装 PDF 阅读器
brew install poppler  # macOS

# 或者确保你有 pdf-tools 所需的工具
#+END_SRC

*文献操作*
| 快捷键  | 功能                            |
|---------+---------------------------------|
| C-c r o | 打开文献（通过 BibTeX key 搜索） |
| C-c r f | 打开文献 PDF 文件               |
| C-c r n | 打开文献笔记                    |
| C-c r i | 插入文献引用                    |
| C-c r k | 插入文献 key                    |
| C-c r s | 插入文献引用（带完整引用格式）   |
| C-c r d | 为当前笔记添加文献关联           |
| C-c r a | 打开文献笔记（如果有）           |

*文献笔记流程*
1. 使用 =C-c n f= 创建文献笔记（选择 =l= 模板）
2. 在创建时输入文献路径或 BibTeX key
3. 使用 =org-noter= 进行批注（需要先打开 PDF）
4. 使用 =org-remark= 在 PDF 上标记重点

*批注与标记*
| 快捷键  | 功能                    |
|---------+-------------------------|
| C-c n m | org-remark 标记选中文本 |
| C-c n o | org-remark 打开标记列表 |

**6. 标签管理**

*定义的标签*
系统预定义了以下标签快捷键：
- =@work= (w) - 工作相关
- =@personal= (p) - 个人事务
- =@blog= (b) - 博客任务
- =@reading= (r) - 阅读相关
- =@idea= (i) - 想法记录
- =@question= (q) - 问题待解决
- =@learning= (l) - 学习笔记
- =@project= (j) - 项目相关

在任务行末尾按 =C-c C-c= 可以快速添加标签

*标签统计*

**8. 博客写作**

* 常用场景

**场景1：快速记录想法**
1. 随时按 =F8= 创建笔记
2. 记录想法内容
3. 添加标签（如 =@idea=）
4. 后续整理时，按 =C-c a g= 查看所有待处理的想法

**场景2：读书笔记**
1. 准备好 PDF 文件（放在 =~/Documents/org/library/=）
2. 按 =C-c n f= 创建文献笔记
3. 选择 =l= 模板，输入文献信息
4. 使用 =org-noter= 进行批注（需要配置）
5. 使用 =org-remark= 标记重点

**场景3：会议记录**
1. 会议开始前，按 =F7= 创建待办
2. 或使用 =C-c c= 选择 =m= 模板
3. 记录参与人员、讨论内容
4. 在"行动项"部分记录后续任务

**场景4：问题解决**
1. 遇到问题时，按 =C-c n f= 创建笔记
2. 选择 =q= 模板（question）
3. 在"探索过程"中记录尝试的方案
4. 在"结论"部分记录最终解决方案
5. 使用 =C-c n i= 链接到相关笔记

**场景5：博客写作**
1. 按 =C-c n f= 选择 =p= 模板创建博客草稿
2. 编写内容，插入图片 =C-c n v=
3. 插入代码块，使用 =C-c C-f= 格式化
4. 完成后按 =C-c h e= 导出
5. 按 =C-c h E= 启动预览查看效果

**场景6：项目跟踪**
1. 为项目创建专门笔记，添加 =@project= 标签
2. 使用 =C-c a t= 按标签筛选项目相关任务
3. 使用 =C-c c t= 查看项目投入的时间
4. 项目完成后使用 =C-c w a= 归档笔记

**场景7：每日回顾**
1. 按 =C-c n d= 创建或查看今日日记
2. 查看今日计划完成情况
3. 使用 =C-c C-t= 查看今日时间分配
4. 为明天的任务创建 TODO

* 高级技巧

**1. 批量操作**
- 查找孤儿笔记后，批量链接到相关笔记
- 使用标签统计识别不常用的标签，考虑合并
- 定期运行 =C-c w o= 清理孤立笔记

**2. 搜索技巧**
- 使用 consult 的 orderless 模式可以空格分隔多个关键词
- 标签搜索可以使用通配符，如 =@work*= 搜索所有工作相关标签

**3. 图片管理**
- 经常整理图片到 assets 文件夹，避免混乱
- 使用相对路径确保笔记可以移动

**4. 时间追踪**
- 在开始任务前使用 =C-c C-x C-i= 开始计时
- 完成后使用 =C-c C-x C-o= 停止计时
- 定期查看时间报告优化工作流程

* 配置自定义

**修改路径**
编辑 =~/.emacs.d/config/config-default.el=，修改以下变量：

#+BEGIN_SRC elisp
;; Hugo 博客路径
(defvar my/hugo-root "~/Documents/hugo/")
(defvar my/hugo-blog-dir "~/Documents/hugo/blog/")

;; 文献管理路径
(defvar my/bibliography-file "~/Documents/org/references.bib")
(defvar my/library-path "~/Documents/org/library/")
(defvar my/lit-notes-path "~/Documents/org/roam/lit/")
#+END_SRC

**添加自定义标签**
编辑 =~/.emacs.d/config/config-org.el= 中的 =org-tag-alist=：

#+BEGIN_SRC elisp
(setq org-tag-alist
      '(("@work" . ?w)
        ("@yourtag" . ?y)  ; 添加你的标签
        ))
#+END_SRC

* 故障排除

**问题：Org Roam 数据库未同步**
解决：按 =M-x org-roam-db-sync= 手动同步

**问题：图片无法粘贴**
解决：确保已安装 =pngpaste=（macOS）或确认剪贴板中有图片

**问题：LSP 功能不工作**
解决：
1. 检查是否安装了对应的 language server
2. 按 =M-x eglot= 手动启动
3. 查看 =*eglot-events*= 缓冲区获取错误信息

**问题：博客导出失败**
解决：
1. 检查 =my/hugo-blog-dir= 路径是否正确
2. 确认 ox-hugo 已正确安装
3. 查看 =*Messages*= 缓冲区获取错误信息
