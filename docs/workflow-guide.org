* 快速入门

** 启动后

- 顶部 Dashboard 出现，导航按钮:
  - 📥 Inbox / 🔭 Studies / 🏛️ Principles  → 打开对应 =.org= 文件
  - 💻 Code → 切换项目 (=project-switch-project=)
- mode-line 是 doom-modeline 风格，主题 doom-one（macOS 暗色自动跟随）
- 终端下: =emacs -nw=

** 目录布局

启动时自动创建 =~/Documents/org/=:

| 文件 | 用途 |
|------+------|
| =inbox.org=    | 想法收集（孵化流入口） |
| =todos.org=    | 执行流任务 |
| =projects.org= | 专题研究 |
| =notes.org=    | 底层模型/笔记 |
| =blog.org=     | Hugo 博客源 |

Hugo 站点: =~/Documents/hugo/ygwa.github.io/=（需自行 =git clone=）

* 核心工作流

** 1. 收集与整理 (Org Capture)

=C-c c= 触发 org-capture，模板:

| 键 | 模板 | 写入位置 |
|----|------|---------|
| =t= | Todo Task       | =todos.org= → Tasks |
| =i= | Inbox / Idea    | =inbox.org= → Inbox, 标签 =NOTE= |
| =q= | Question        | =inbox.org= → Inbox, 标签 =QUESTION= |
| =b= | Blog Post (Hugo) | =blog.org= → Blog Posts |

=C-c a= 打开 org-agenda，看 todos/projects/inbox/blog 四文件的待办。

=C-c l= 存链接，备用插入到笔记里。

** 2. 文献管理 (Citar)

文献库: =~/Documents/org/references.bib=，PDF 目录: =~/Documents/org/library/=.

- =C-c r o= → 打开文献（按 BibTeX key）
- =C-c r i= → 插入引用

** 3. 搜索与导航

| 键 | 功能 |
|----|------|
| =C-s=         | consult-line（当前 buffer） |
| =C-c g=       | consult-git-grep（项目内） |
| =C-c k=       | consult-ripgrep（项目内） |
| =C-c C-r=     | consult-recent-file |
| =C-x b=       | consult-buffer |
| =M-y=         | consult-yank-pop（增强 kill-ring） |
| =C-x r b=     | consult-bookmark |
| =C-x l=       | consult-locate |
| =C-; / C-.=   | embark-dwim / embark-act（上下文动作） |
| =M-o=         | ace-window（分屏跳转） |
| =C-c j / J / w= | avy（字符/行/词跳转） |

** 4. 项目导航 (project.el)

自动识别 Git 仓库 + =package.json= / =requirements.txt= / =.project= 目录。

| 键 | 功能 |
|----|------|
| =C-c p f= | project-find-file |
| =C-c p b= | project-switch-to-buffer |
| =C-c p d= | project-dired |
| =C-c p v= | project-vc-dir（=magit-status=） |
| =C-c p s= | project-shell（vterm） |
| =C-c p g= | project-find-regexp |

** 5. 终端

=C-`=  →  vterm-toggle（在项目范围内 toggle vterm）

** 6. 开发辅助

*** LSP（Eglot，Emacs 30 内置）

TS/TSX/JS 自动启 eglot。Rust 需先装 =rust-analyzer=。

通用键（在 eglot-mode-map）:

| 键 | 功能 |
|----|------|
| =C-c s r= | rename |
| =C-c s f= | format |
| =C-c s a= | code-actions |
| =C-c s h= | help-at-point |
| =C-c s d= | find-declaration |
| =C-c s i= | find-implementation |
| =C-c s t= | find-typeDefinition |

TypeScript 模式额外:

- =C-c C-f= → apheleia-format-buffer（prettier）
- =C-c s o= → code-action-organize-imports

*** Web 项目

- =C-c r n= → my/npm-run（自动检测 pnpm/yarn/npm，列出 scripts 选一个跑）
- =M-x my/check-web-dev-tools= → 检查 vtsls/prettier/eslint/tailwind 是否齐
- ESLint 自动启用（需项目里有 =.eslintrc.js=）

** 7. 博客写作 (ox-hugo)

写: =C-c c b= 模板（需 blog.org 有 "Blog Posts" 标题）

编辑: blog.org 任一子树，=#+TITLE= 即文章标题，=#+EXPORT_FILE_NAME:= 是 slug

自动 export: 保存 blog.org 时自动生成 Markdown 到 Hugo

手动命令:

- =M-x org-hugo-export-wim-to-md= → 当前子树
- =M-x org-hugo-export-subtree= → 当前子树
- =M-x org-hugo-export-project= → 全量

** 8. 字典 / 翻译

=C-c y= → youdao-dictionary-search-at-point+

* 配置自定义

** 修改路径

编辑 =~/.emacs.d/config/config-org.el=:

#+BEGIN_SRC elisp
(defvar my/org-root-dir         "~/Documents/org/")
(defvar my/org-inbox-file       (expand-file-name "inbox.org"    my/org-root-dir))
(defvar my/org-todo-file        (expand-file-name "todos.org"    my/org-root-dir))
(defvar my/org-projects-file    (expand-file-name "projects.org" my/org-root-dir))
(defvar my/org-notes-file       (expand-file-name "notes.org"    my/org-root-dir))
(defvar my/org-hugo-posts-file  (expand-file-name "blog.org"     my/org-root-dir))
(defvar my/hugo-root            "~/Documents/hugo/ygwa.github.io/")
#+END_SRC

** 添加 Capture 模板

编辑 =~/.emacs.d/config/config-org.el= 中 =org-capture-templates=.

** 添加 TODO 关键字

编辑 =~/.emacs.d/config/config-org.el= 中 =org-todo-keywords=.

** 换主题

编辑 =~/.emacs.d/config/config-gui.el= 第 81 行 =my/theme= 变量。可选:

- =doom-one= / =doom-one-light=（深 / 浅）
- =doom-dracula= / =doom-gruvbox= / =doom-solarized-dark= 等

** 改 mode-line 高度

编辑 =~/.emacs.d/config/config-gui.el= 中 =doom-modeline-height=.

* 故障排除

** LSP 不工作

1. 检查 language server 是否安装（=which vtsls=，=which typescript-language-server=）
2. =M-x my/check-web-dev-tools= 看 web 工具状态
3. 查看 =*eglot-events*= 缓冲区

** 博客导出失败

1. 确认 =my/hugo-root= 路径正确，Hugo 站点已 clone
2. =M-x org-hugo-export-wim-to-md= 报错时查 =*Messages*=
3. 确认 ox-hugo 已装（=M-x list-packages=）

** Doom-modeline / Nerd-icons 不显示

1. =M-x doom-modeline-mode= 确认 ON
2. 字体: =M-x nerd-icons-install-fonts= 下载 Nerd Font
3. macOS GUI: 在终端/Emacs 里设置字体为已安装的 Nerd Font
4. TUI: 终端需配 Nerd Font（iTerm2 / Kitty / Alacritty 都支持）

** 主题没切

- 手动 =M-x load-theme RET doom-one RET=
- macOS 暗色自动跟随: =M-x describe-variable RET my/theme= 看当前值

** 包装不上 (MELPA 404)

1. =M-x package-refresh-contents= 刷新索引
2. 重启 Emacs
3. 仍然失败: 临时换 =https://melpa.org/packages/= 作为源
