# Magit Git 管理指南

Magit 是 Emacs 中功能强大的 Git 界面，提供直观且高效的版本控制操作。它支持几乎所有 Git 功能，包括提交、分支管理、合并、变基等。

## 🚀 快速开始

### 打开 Magit 状态

在 Emacs 中打开项目目录，然后：

- 使用命令：`M-x magit-status`
- 或使用快捷键（如果已绑定）

这会打开 Magit 状态缓冲区，显示当前 Git 仓库的状态。

### 基本操作流程

1. **查看状态** → `M-x magit-status`
2. **暂存文件** → 在状态缓冲区中按 `s`
3. **提交更改** → 按 `c` 创建提交
4. **推送更改** → 按 `p` 推送到远程

## 🎯 核心概念

### Magit 状态缓冲区

Magit 状态缓冲区是 Magit 的核心界面，显示：

- **头部信息** - 当前分支、远程跟踪信息
- **未暂存的更改** - 工作区中的修改
- **已暂存的更改** - 暂存区中的修改
- **未跟踪的文件** - 新文件
- **最近的提交** - 提交历史

### 快捷键模式

Magit 使用单字母快捷键，这些快捷键：

- **上下文相关** - 在不同区域按相同键可能有不同效果
- **可组合** - 可以连续按多个键执行复杂操作
- **有提示** - 在状态缓冲区底部显示可用操作

## 🎨 主要功能

### 1. 文件操作

**暂存和取消暂存：**
- `s` - 暂存当前项（文件、块或行）
- `u` - 取消暂存当前项
- `S` - 暂存所有更改
- `U` - 取消暂存所有更改

**查看差异：**
- `d` - 显示差异
  - `d d` - 显示工作区差异
  - `d c` - 显示暂存区差异
  - `d w` - 显示工作区差异（忽略空白）
- `D` - 显示提交差异

**丢弃更改：**
- `k` - 丢弃更改（小心使用！）
- `x` - 重置到 HEAD（丢弃所有未提交的更改）

### 2. 提交操作

**创建提交：**
- `c` - 提交菜单
  - `c c` - 创建提交（`magit-commit-create`）
  - `c a` - 修改最后一次提交（amend）
  - `c e` - 扩展提交（extend）
  - `c w` - 重写提交（rewrite）

**提交信息编辑：**
- 在提交信息缓冲区中：
  - `C-c C-c` - 完成提交
  - `C-c C-k` - 取消提交
  - `C-c C-a` - 添加签名

### 3. 分支管理

**分支操作：**
- `b` - 分支菜单
  - `b c` - 创建新分支（`magit-branch-create`）
  - `b b` - 切换分支（`magit-branch-checkout`）
  - `b w` - 重命名分支（`magit-branch-rename`）
  - `b k` - 删除分支（`magit-branch-delete`）
  - `b m` - 合并到当前分支（`magit-branch-merge`）

**查看分支：**
- `b b` - 列出所有分支并切换
- `b s` - 创建并切换分支（spawn）

### 4. 远程操作

**拉取和获取：**
- `f` - 获取菜单
  - `f f` - 从远程获取（`magit-fetch`）
  - `f a` - 从所有远程获取
  - `f p` - 拉取（fetch + merge，`magit-pull`）
  - `f u` - 拉取并变基（fetch + rebase）

**推送：**
- `p` - 推送菜单
  - `p p` - 推送到当前分支的推送远程（`magit-push-current-to-pushremote`）
  - `p u` - 推送到上游分支
  - `p e` - 推送到其他远程
  - `p t` - 推送标签

### 5. 合并和变基

**合并：**
- `m` - 合并菜单
  - `m m` - 合并分支（`magit-merge`）
  - `m e` - 编辑合并提交信息
  - `m a` - 中止合并（`magit-merge-abort`）

**变基：**
- `r` - 变基菜单
  - `r r` - 开始变基（`magit-rebase`）
  - `r e` - 编辑变基
  - `r s` - 跳过当前提交
  - `r a` - 中止变基（`magit-rebase-abort`）
  - `r c` - 继续变基（`magit-rebase-continue`）

### 6. 日志和历史

**查看日志：**
- `l` - 日志菜单
  - `l l` - 显示提交日志（`magit-log`）
  - `l o` - 显示其他分支的日志
  - `l h` - 显示头部日志
  - `l a` - 显示所有分支的日志
  - `l f` - 显示文件日志

**在日志中操作：**
- `RET` - 查看提交详情
- `d` - 显示提交差异
- `a` - 应用提交（cherry-pick）
- `c` - 创建提交
- `f` - 创建修复提交

### 7. 暂存区（Stash）

**暂存区操作：**
- `z` - 暂存区菜单
  - `z z` - 创建暂存区（`magit-stash`）
  - `z a` - 应用暂存区（`magit-stash-apply`）
  - `z p` - 弹出暂存区（`magit-stash-pop`）
  - `z d` - 删除暂存区（`magit-stash-drop`）
  - `z w` - 创建包含未跟踪文件的暂存区

## 💡 使用场景

### 场景 1: 基本提交流程

1. 修改文件后，运行 `M-x magit-status`
2. 按 `s` 暂存要提交的文件
3. 按 `c c` 创建提交
4. 输入提交信息
5. 按 `C-c C-c` 完成提交
6. 按 `p p` 推送到远程

### 场景 2: 创建和切换分支

1. 运行 `M-x magit-status`
2. 按 `b c` 创建新分支
3. 输入分支名称
4. 开始开发
5. 完成后按 `b b` 切换回主分支

### 场景 3: 合并分支

1. 切换到目标分支（如 `main`）
2. 运行 `M-x magit-status`
3. 按 `m m` 合并分支
4. 选择要合并的分支
5. 解决冲突（如果有）
6. 完成合并

### 场景 4: 变基操作

1. 在功能分支上运行 `M-x magit-status`
2. 按 `r r` 开始变基
3. 选择目标分支（如 `main`）
4. 在变基过程中：
   - 编辑提交：`r e`
   - 跳过提交：`r s`
   - 继续变基：`r c`
   - 中止变基：`r a`

### 场景 5: 查看提交历史

1. 运行 `M-x magit-status`
2. 按 `l l` 查看提交日志
3. 使用 `C-n`/`C-p` 导航提交
4. 按 `RET` 查看提交详情
5. 按 `d` 查看提交差异

### 场景 6: 使用暂存区

1. 有未完成的更改，需要切换分支
2. 运行 `M-x magit-status`
3. 按 `z z` 创建暂存区
4. 输入暂存区消息
5. 切换分支进行其他工作
6. 切换回来后，按 `z a` 应用暂存区

### 场景 7: 解决冲突

1. 合并或变基时出现冲突
2. 在状态缓冲区中看到冲突文件
3. 打开冲突文件，手动解决冲突
4. 解决后，在 Magit 中按 `s` 暂存文件
5. 继续合并/变基：按 `r c`（变基）或完成合并

## 🔧 高级功能

### 1. 交互式变基

Magit 提供了强大的交互式变基功能：

1. 按 `r r` 开始变基
2. 选择目标分支
3. 在变基缓冲区中：
   - `p` - pick（使用提交）
   - `r` - reword（修改提交信息）
   - `e` - edit（编辑提交）
   - `s` - squash（合并到上一个提交）
   - `f` - fixup（类似 squash，但丢弃提交信息）
   - `d` - drop（删除提交）
   - `x` - exec（执行命令）

### 2. Cherry-pick

从其他分支选择性地应用提交：

1. 按 `l l` 查看日志
2. 导航到要应用的提交
3. 按 `a` 应用提交（cherry-pick）

### 3. 补丁操作

创建和应用补丁：

1. 按 `w` 进入补丁菜单
2. `w c` - 从提交创建补丁
3. `w a` - 应用补丁

### 4. 子模块支持

Magit 支持 Git 子模块：

- 在状态缓冲区中显示子模块
- 可以更新和管理子模块

### 5. 工作树（Worktree）

管理多个工作树：

- `b w` - 在工作树中创建分支
- 支持多个工作目录

## ⚙️ 配置和自定义

### 当前配置

本配置中的 Magit 设置（在 `config/config-package.el` 中）：

```elisp
(use-package magit
  :ensure t
  :config
  ;; 推送时不总是验证
  (setq magit-push-always-verify nil)
  ;; 恢复缓冲区
  (setq magit-revert-buffers t))
```

### 常用配置选项

可以在配置文件中添加以下选项：

```elisp
(use-package magit
  :ensure t
  :config
  ;; 自动刷新状态
  (setq magit-auto-revert-mode t)
  
  ;; 提交时自动填充签名
  (setq magit-commit-show-diff nil)
  
  ;; 显示更多提交信息
  (setq magit-log-margin '(t age-abbreviated author-width))
  
  ;; 自定义暂存区格式
  (setq magit-stash-branch-format "stash@{%gd %gs}")
  
  ;; 禁用某些确认提示
  (setq magit-no-confirm '(discard))
  
  ;; 自定义差异视图
  (setq magit-diff-refine-hunk 'all))
```

### 自定义快捷键

可以添加全局快捷键：

```elisp
(global-set-key (kbd "C-x g") 'magit-status)
(global-set-key (kbd "C-x M-g") 'magit-dispatch)
```

## ❓ 常见问题

### Q1: 如何撤销最后一次提交？

**解决方案：**
1. 运行 `M-x magit-status`
2. 按 `c w` 重写提交
3. 选择要修改的提交
4. 或使用 `c a` 修改最后一次提交

### Q2: 如何查看两个提交之间的差异？

**解决方案：**
1. 按 `l l` 查看日志
2. 导航到第一个提交，按 `d`
3. 或使用 `d r` 显示范围差异

### Q3: 如何恢复已删除的分支？

**解决方案：**
1. 按 `l a` 查看所有分支的日志
2. 找到删除分支的提交
3. 按 `b c` 创建新分支指向该提交

### Q4: 如何修改远程仓库地址？

**解决方案：**
1. 按 `M` 进入远程菜单
2. `M r` 重命名远程
3. `M u` 设置远程 URL

### Q5: Magit 状态缓冲区不更新？

**解决方案：**
- 按 `g` 手动刷新
- 或设置 `magit-auto-revert-mode` 为 `t`

### Q6: 如何查看文件的 Git 历史？

**解决方案：**
1. 在文件缓冲区中，运行 `M-x magit-log-buffer-file`
2. 或按 `l f` 然后选择文件
