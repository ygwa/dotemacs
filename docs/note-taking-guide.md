# 笔记管理系统使用指南

本指南详细介绍如何使用 Emacs + Org-roam 进行知识管理，涵盖日常笔记、文献阅读、博客写作的完整工作流。

## 目录结构

```
~/Documents/org/
├── inbox.org           # 收集箱（快速捕获）
├── references.bib      # 文献库
├── library/            # PDF/电子书存储
└── roam/               # Org-roam 笔记库
    ├── concepts/       # 概念笔记
    ├── lit/            # 文献笔记
    ├── questions/      # 问题驱动笔记
    ├── ideas/          # 灵感记录
    ├── posts/          # 博客草稿
    └── daily/          # 日记（自动按日期）
```

## 使用场景与工作流

### 场景 1：日常笔记与日记

**晨间规划工作流：**

1. 按 `C-c n j` 打开今日日记
2. 在"今日计划"下添加任务（使用 `- [ ]` 复选框）
3. 按 `C-c n c`，选择 `m`（晨间回顾）记录状态

**记录灵感或想法：**

1. 任何时候按 `C-c n c`，选择 `d`（默认）
2. 输入内容，自动带时间戳保存到今日日记

**晚间回顾：**

1. 按 `C-c n j` 打开今日日记
2. 按 `C-c n c`，选择 `e`（晚间回顾）
3. 记录完成事项、挑战和明日计划

### 场景 2：知识卡片笔记（Zettelkasten）

**创建概念笔记：**

1. 按 `C-c n f` 打开笔记搜索
2. 输入概念名称（如"函数式编程"）
3. 如果不存在，按回车创建
4. 选择模板 `d`（default/concept）
5. 编写笔记内容

**建立笔记间链接：**

1. 在笔记中，按 `C-c n i`
2. 搜索要链接的笔记
3. 选中后自动插入链接

**查看反向链接：**

1. 打开任意笔记
2. 按 `C-c n l` 显示反向链接面板
3. 查看哪些笔记引用了当前笔记

**可视化知识网络：**

1. 按 `C-c n u` 启动 org-roam-ui
2. 在浏览器中查看知识图谱
3. 点击节点可跳转到对应笔记

### 场景 3：问题驱动学习

当你遇到一个需要探究的问题时：

1. 按 `C-c n f` 打开笔记搜索
2. 输入问题（如"为什么 Rust 不需要垃圾回收"）
3. 选择模板 `q`（question）
4. 自动生成结构化模板：
   - 问题描述
   - 探索过程
   - 结论

### 场景 4：阅读 PDF/电子书并做笔记

**阅读 PDF：**

1. 在 Emacs 中打开 PDF 文件（自动使用 pdf-tools）
2. 使用标准阅读快捷键浏览

**创建文献笔记：**

1. 按 `C-c n f` 创建新笔记
2. 选择模板 `l`（literature）
3. 输入 PDF 文件路径
4. 使用 org-noter 进行精读批注

**使用 org-noter：**

1. 在文献笔记中，按 `M-x org-noter`
2. 自动打开 PDF 和笔记的双栏视图
3. 在 PDF 中阅读，笔记自动同步位置

### 场景 5：博客写作与发布

**方式 A：从 org-roam 笔记发布博客**

1. 按 `C-c n f`，创建或打开笔记
2. 选择模板 `p`（blog post）
3. 填写分类、标签、描述
4. 编写文章内容
5. 完成后按 `C-c b e` 导出到 Hugo

**方式 B：直接在 Hugo 目录创建**

1. 按 `C-c b n`
2. 输入文章标题
3. 自动创建带 Hugo front-matter 的草稿
4. 编写完成后按 `C-c b e` 导出

**预览与发布：**

1. 按 `C-c C-e` 打开 Easy Hugo 管理界面
2. 按 `p` 预览文章
3. 按 `P` 发布到服务器

### 场景 6：插入图片与截图

**从剪贴板粘贴图片：**

1. 复制图片到系统剪贴板（如从浏览器、截图工具）
2. 在 org 文件中按 `C-c n y`
3. 图片自动保存到 `./images/` 目录并插入链接

**截取屏幕截图：**

1. 在 org 文件中按 `C-c n s`
2. 使用系统截图工具选择区域
3. 截图自动保存并插入

**拖拽图片：**

1. 从 Finder/文件管理器拖拽图片到 Emacs
2. 自动复制并插入链接

**删除图片：**

1. 将光标放在图片链接上
2. 按 `C-c n d`
3. 同时删除链接和图片文件

## 任务管理

### TODO 状态流转

```
TODO → INPROGRESS → DONE
         ↓
      WAITING → DONE
         ↓
     CANCELLED
```

**切换状态：** 在任务行按 `C-c C-t`

### 查看任务

1. 按 `C-c a` 打开 Agenda
2. 按 `t` 查看所有 TODO
3. 按 `m` 按标签过滤

## 进阶技巧

### 使用标签组织笔记

在任意标题后添加标签：

```org
* 我的笔记 :tag1:tag2:
```

常用标签建议：
- `:draft:` - 草稿状态
- `:review:` - 待复习
- `:important:` - 重要内容

### 笔记模板变量

在 org-roam 模板中可用的变量：
- `${title}` - 笔记标题
- `${slug}` - URL 友好的文件名
- `%U` - 时间戳
- `%?` - 光标位置
- `%^{prompt}` - 交互式输入

### 批量导出博客

在包含多篇文章的 org 文件中：

```org
#+hugo_base_dir: ~/Documents/hugo/blog/

* 文章一
:PROPERTIES:
:EXPORT_FILE_NAME: article-1
:END:

内容...

* 文章二
:PROPERTIES:
:EXPORT_FILE_NAME: article-2
:END:

内容...
```

按 `C-c C-e H A` 批量导出所有子树。

## 常见问题

### Q: 图片粘贴不工作？

确保已安装 `org-download` 包。重启 Emacs 后运行：
```
M-x package-install RET org-download RET
```

### Q: 日记文件在哪里？

默认位置：`~/Documents/org/roam/daily/`

### Q: 如何查看所有笔记的关系图？

按 `C-c n u` 启动 org-roam-ui，然后在浏览器中打开 http://localhost:35901

### Q: 如何在笔记间快速跳转？

- 使用 `C-c n f` 搜索所有笔记
- 在链接上按 `RET` 跳转
- 使用 `C-c n l` 查看反向链接

### Q: 博客图片如何处理？

ox-hugo 会自动将 `./images/` 目录下的图片复制到 Hugo 的 `static/ox-hugo/` 目录。
